# SufferingIM

SufferingIM is a Python-based instant messaging application currently under development.

## About

SufferingIM aims to provide a lightweight, self-hostable instant messaging solution. The project is in its early stages, with the foundational structure in place and core features being actively developed.

## AI Usage

This project uses AI assistance as part of the development workflow. Specifically:

- **GitHub Copilot** is used within the IDE to suggest code completions, generate boilerplate, and help draft implementations for new features.
- **GitHub Copilot coding agent** is used to autonomously implement tasks, perform code reviews, and assist with refactoring.
- AI-generated code is reviewed by human developers before being merged to ensure correctness, security, and alignment with the project's goals.
- AI tools are used to accelerate development, but all architectural decisions and final code quality checks remain the responsibility of the project maintainers.
